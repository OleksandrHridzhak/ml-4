## ✅ Виконані вимоги

- [x] **Етап 1. EDA та попередня обробка:**
  - Досліджено 16 числових ознак та 7 класів (Dry Bean Dataset)
  - Виявлено мультиколінеарність (|r| ≥ 0.95), обґрунтовано Ridge-регуляризацію
  - Стратифіковане розбиття без Data Leakage: Global Test (15%), Global Validation (15%), FL Train Pool (70%)
  - StandardScaler на Train Pool та верифікація федеративного розрахунку μ, σ²

- [x] **Етап 2. Логістична регресія виключно на NumPy:**
  - Чисельно стабільний Softmax із відніманням максимуму рядка
  - Cross-Entropy Loss + Ridge-регуляризація ((λ / 2) · ||W||_F²)
  - Повністю векторизовані градієнти без циклів for по семплах

- [x] **Етап 3. Централізований бейзлайн (Baseline):**
  - Оптимальні параметри: α = 0.1, B = 64, λ = 10⁻⁴
  - Test Accuracy: **91.82%** | Macro-F1: **0.9312** | Balanced Acc: **0.9298**
  - Побудовано матриці невідповідностей (Confusion Matrix)

- [x] **Етап 4. Розподіл даних (K=5 клієнтів):**
  - IID та Dirichlet Non-IID (α ∈ {5.0, 1.0, 0.3})
  - Теплові карти та гістограми розподілу сортів між клієнтами

- [x] **Етап 5. Симуляція федеративного навчання (FedAvg):**
  - Архітектура Server-Clients без витоку сирих даних
  - Зважена агрегація FedAvg: w_{t+1} = Σ (n_k / N) · w_{t+1}^k

- [x] **Етап 6. Обов'язкові експерименти:**
  - Порівняння: ізольовані локальні (59–85%) vs FedAvg (**90.21–91.43%**) vs Baseline (**91.82%**)
  - Експеримент 1: вплив неоднорідності даних (Dirichlet α ∈ {5.0, 1.0, 0.3})
  - Експеримент 2: вплив локальних епох (E ∈ {1, 5, 10}) та аналіз **Client Drift**

- [x] **Розділ 3. Теоретичні питання:**
  - Вичерпні відповіді на всі 17 теоретичних питань методички
