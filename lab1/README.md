## Ключові результати

### 1. Реалізація моделі та оптимізації
* Модель лінійної регресії ($\hat{y} = Xw + b$) та градієнтні методи реалізовані **з нуля засобами виключно `numpy`**.
* Використано повністю векторизоване обчислення без неефективних циклів `for`.
* Реалізовано 3 методи градієнтного спуску:
  * **Batch Gradient Descent:** ідеально монотонна крива спуску функції втрат, стабільна збіжність.
  * **Stochastic Gradient Descent (SGD):** швидке просування з характерними випадковими коливаннями за рахунок оновлення після кожного окремого семплу.
  * **Mini-batch Gradient Descent ($B=32$):** найкращий баланс між векторизованою продуктивністю `numpy` та здатністю до швидкої збіжності.

### 3. Перевірка статистичних припущень
1. **Лінійність (Linearity):** графік *Residuals vs Fitted* демонструє рівномірний розподіл залишків навколо нуля без сильної нелінійної кривизни.
2. **Нормальність (Normality):** Q-Q plot показує відхилення на важких «хвостах» (наявні дорогі або аномальні будинки), проте в центральній частині розподіл наближений до нормального.
3. **Гомоскедастичність (Homoscedasticity):** дисперсія залишків дещо зростає зі збільшенням вартості нерухомості (візуалізовано на графіку *Scale-Location*).
4. **Мультиколінеарність (Multicollinearity):** проведено VIF-аналіз (Variance Inflation Factor); взаємозалежні змінні (наприклад, площа гаража та кількість машин) відфільтровано/враховано.

### 4. Вплив масштабування (Експеримент)
* Без стандартизації ознак поверхня функції втрат набуває витягнутої яружної форми, що призводить до коливань градієнта та вимагає надзвичайно малого learning rate ($\alpha$).
* Після стандартизації (StandardScaler, параметри розраховані суворо на Train без Data Leakage) поверхня Cost стає ізотропною, що дозволяє суттєво пришвидшити навчання зі стабільним кроком.
