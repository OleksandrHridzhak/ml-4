## Лабораторні роботи

### [Лабораторна робота 1: Лінійна регресія, оптимізація та статистичний аналіз](lab1/)
* **Датасет:** Ames Housing Dataset (*House Prices: Advanced Regression Techniques*).
* **Ключові етапи:**
  1. **EDA та інженерія ознак:** аналіз пропущених значень, кореляційний аналіз, відбір інформативних фіч без витоку даних (*Data Leakage*), масштабування (StandardScaler) та кодування категоріальних змінних.
  2. **Реалізація Лінійної Регресії виключно на NumPy:** повна відсутність циклів `for` при обчисленні Cost Function (MSE) та градієнтів за рахунок матричної векторизації.
  3. **3 варіанти градієнтного спуску:**
     - **Batch GD:** плавна та монотонна збіжність;
     - **SGD:** швидкі кроки з характерними флуктуаціями;
     - **Mini-batch GD ($B=32$):** оптимальний компроміс швидкості, утилізації векторних інструкцій та стабільності.
  4. **Оцінка якості та метрика $R^2$:**
     - Train: $\approx 0.811$
     - Validation: $\approx 0.771$
     - Test: $\approx 0.779$
  5. **Перевірка статистичних припущень регресії:**
     - Лінійність (Residuals vs Fitted);
     - Нормальність залишків (Q-Q plot, гістограма та Shapiro-Wilk);
     - Гомоскедастичність (Scale-Location plot, Breusch-Pagan);
     - Мультиколінеарність (VIF).
  6. **Дослідницький експеримент:** порівняння поведінки збіжності градієнтного спуску з масштабуванням ознак та без нього.
